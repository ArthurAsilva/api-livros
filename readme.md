# 📚 API de Livros

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de uma **API de Livros**, realizada durante as aulas de **SWII (Sistemas Web II)** na **ETEC Maria Cristina Medeiros (ETEC MCM)**.

A atividade teve como objetivo colocar em prática os conhecimentos aprendidos em aula sobre desenvolvimento de APIs, requisições HTTP, organização de dados e comunicação entre aplicações.

A API permite trabalhar com informações relacionadas a livros, possibilitando operações de consulta e gerenciamento dos dados.

## 🎯 Objetivo

O principal objetivo do projeto é desenvolver uma API funcional para o gerenciamento de livros, aplicando na prática os conceitos estudados durante as aulas de SWII.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Node.js
- API REST
- JSON

## 📖 Funcionalidades

A API foi desenvolvida para trabalhar com dados de livros, permitindo operações como:

- 📕 Cadastrar livros
- 🔎 Consultar livros
- ✏️ Alterar informações
- 🗑️ Excluir livros
- 📋 Listar os livros disponíveis

## 🚀 Como executar o projeto

1. Clone este repositório:
```bash
git clone URL_DO_REPOSITORIO
```

2. Entre na pasta do projeto:
```bash
cd nome-do-projeto
```

3. Instale as dependências:
```bash
npm install
```

4. Execute o projeto:
```bash
npm start
```

5. Acesse a API através da porta configurada no projeto.
